# 大壮危险 5

独立分支 `feature/chunky-strategy`，从法师原生危险 5 通关后合并的 master 创建。

本机原生资源：生命属性收益 +25%，每 3 永久生命提供 1% 伤害，拾取治疗 +3；移速属性收益为零，吸血初始 -100，再生和闪避属性收益减半。

0.6.14 首轮用六霰弹枪，沿用远程避险与精英/Boss/树目标优先级。生命兼顾生存和伤害，投资护甲、远伤、攻速，增加射程和拾取治疗的评分。不购买无效移速和吸血属性；再生、闪避按原生收益倍率评分。生命带来的伤害价值仍为启发式，未精确模拟每件物品跨越三点生命门槛后的取整。

纯策略回归覆盖生命收益、无效属性和拾取治疗；原生自检检查霰弹枪准入、拒绝冲锋枪。原速、不录视频。首局通关效果待实战验证，原生胜利及存档确认前不合并。

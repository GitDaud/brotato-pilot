# 狂人危险 5

独立分支 `feature/crazy-strategy`，从异变体原生通关后已合并的 master 创建。

原生资源确认：精准武器 +100 射程、25% 攻速、额外一把小刀，负面为 -30 闪避、-10 工程、-10 远伤。

0.6.12 首轮采用六把小刀，使用原生购买和合成。共用近战接敌及避险，禁止误买拳头或远伤武器。优先近伤、暴击基础、护甲、生命及移速；暴击属性到 35 后降低评分，这是待实测的启发式，并非通用上限。护甲优先于修复初始负闪避。

参考玩家建议：https://www.reddit.com/r/brotato/comments/1fjgda9/any_tips_to_win_with_crazy/

纯策略回归已通过，包括近远伤隔离和暴击评分递减。原速、不录视频；危险 5 首局验证中，胜利并核对原生存档之前不合并。

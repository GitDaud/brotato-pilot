# 幸运星危险 5

从老者通关后合并的 master 创建 `feature/lucky-strategy`，按原生角色顺序推进。

原生被动：初始 100 幸运、幸运属性收益 +25%、攻速 -60%、经验收益 -50%；拾取材料时有 75% 概率对随机敌人造成按幸运 15% 缩放的伤害。起手弹弓是本机原生允许的选择。

0.6.19 首轮六弹弓，保留基础远伤和负攻速修复，提升幸运和拾取治疗价值；象宝宝、赛博球增加递减协同评分。原生效果中 `stat_luck` 是这些触发伤害的缩放键，并非直接给予幸运；本角色跳过错误的平坦幸运评分，协同仅计一次。仍保留生命、护甲、速度和树/精英/Boss 优先级。

弹弓弹射及幸运连锁伤害未纳入直击 DPS 近似，250 幸运的评分拐点及道具协同分为待实测启发式。纯策略检查覆盖幸运原生倍率、触发效果和攻速修复；原生自检核对弹弓准入和缩放。原速、不录视频，胜利及原生存档核验前不合并。

# 法师危险 5

独立分支 `feature/mage-strategy`，从狂人危险 5 原生通关后合并的 master 创建。

本机 1.2.0.1 原生资源确认：初始 5 元素伤害、元素属性收益 +25%，自带香肠和蛇；近伤及远伤属性收益为零。电击枪是原生可选起手武器，一级基础伤害 7、元素缩放 80%、基础射程 200。

0.6.13 首轮采用六电击枪，保持远程避险。采购、升级和满槽合成的伤害比较改为元素缩放，元素属性按原生收益倍率计分；兼顾攻速、射程、生命、护甲、速度。香肠和蛇采用递减的额外评分，不套用冲锋枪穿透道具奖励。

武器比较仍是直击伤害近似，未精确模拟燃烧传播、重复施加燃烧和实际命中率。原速、不录视频。通关并核对原生存档前不合并。
